# Java Practice

Classic beginner exercises that reuse concepts from [`java-basics/`](../java-basics/).
Each file has comments and its verified OUTPUT at the bottom.

Run any exercise from its folder, e.g. `java EvenOdd.java`.
Try solving each one yourself first, then compare with the solution.

| # | Exercise | Concepts |
|---|----------|----------|
| 01 | Even / odd | `%`, if-else |
| 02 | Swap two numbers | variables, arithmetic |
| 03 | Largest of three | if / else if, `Math.max` |
| 04 | Simple & compound interest | doubles, `Math.pow`, formatting |
| 05 | Multiplication table | for loop, `printf` |
| 06 | Prime numbers | boolean methods, loops |
| 07 | Reverse a number | `% 10`, `/ 10`, while loop |
| 08 | Armstrong numbers | digits, `Math.pow` |
| 09 | Palindrome string | two pointers, regex cleanup |
| 10 | Count vowels | `Character` helpers |
| 11 | Character frequency | `TreeMap`, `LinkedHashMap` |
| 12 | Second largest | single-pass array scan |
| 13 | Bubble sort | nested loops, swapping |
| 14 | Linear search | O(n) search |
| 15 | Binary search | O(log n) search on sorted arrays |
| 16 | Matrix operations | 2D arrays |
| 17 | FizzBuzz | condition order |
| 18 | Student report card | records, streams, switch expressions |
